# E-Commerce Admin App

This is an **E-Commerce Admin App** that integrates with the **Shopify API** to provide comprehensive CRUD (Create, Read, Update, Delete) operations for managing an online store. The app is designed for administrators to efficiently manage products, inventory,coupones, and more, all through a user-friendly interface.


## Features

- **Product Management**
  - get counts , show all , Search ,Add, edit, or delete products.
  - Manage product descriptions, prices, images.
  - Categorize products and assign vendors for better organization.
    
- **Coupon Management**
  - Create, view, edit, or delete coupons.
  - Set coupon details like discount amounts,first date and expiration dates.
 
## Shopify API Integration

This app leverages the **Shopify API** for real-time synchronization between the Shopify storefront and the admin panel.

## Requirements

- Shopify API credentials (API key, secret key, and access token).
- Admin access to the e-commerce store.
- Minimum Android Version: API Level 24 -> minSdk = 24 Target Android Version: API Level 34 ->targetSdk = 34
